FEATURE EXTRACTION

What the model sees

Six summary features are calculated from each complete recording. These help describe shape and movement without showing every data point.

Research visualization only. The waveform is downsampled for display; features use the complete recording. This is not a diagnostic tool.

HOW IT WORKS

From wave to insight.

01

Prepare

Convert the original MAT recordings into consistent numerical signals and separate them by interictal, preictal and ictal stage.

02

Describe

Extract variation, range, RMS power, zero crossing rate and change rate from each complete signal.

03

Compare

Explore the stage averages and individual examples. A reproducible Python script prepares the data used in this interface.

ABOUT THE PROJECT

Making complex signals
easier to understand.

This portfolio project uses 150 EEG recordings from an open research dataset: 50 per stage. It presents the preparation and feature exploration behind a seizure detection study. Stage labels belong to the source data; the charts do not imply clinical performance. For model training, patient independent validation and further review would be essential.
